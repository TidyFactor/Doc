## ⚡ ما هي مهارة TidyFactor Doc؟

`tidyfactor-doc` هي مهارة معمارية حتمية مخصصة لوكلاء البرمجة بالذكاء الاصطناعي (*Google Antigravity, Claude Code, Cursor, Codex, Windsurf*). تقوم باستقراء قواعد الأكواد والمشاريع البرمجية بدقة وتحويلها إلى توثيقات فنية منظمة ومحفوظة تحت مجلد `/docs` (مراجع API، أدلة المطورين، التعليقات البرمجية، ومواقع Docsify التفاعلية).

---

## 🏛️ الأوامر ومسارات العمل

| نية المطور | الأمر | المسارات وملفات الذاكرة المحملة |
| :--- | :--- | :--- |
| **"تجهيز وهيكلة مجلد التوثيق"** | `init` | `workflows/init-docs.md` + `memory/doc-tree.md` |
| **"استقراء وفحص الكود والمشروع"** | `collect` | `workflows/collect.md` + `memory/collection-sources.md` |
| **"توليد مراجع API وأدلة التشغيل"** | `generate` | `workflows/generate-*.md` + `memory/doc-templates.md` |
| **"تحويل التوثيقات إلى موقع Docsify"** | `docsify` | `workflows/docsify.md` + `memory/docsify-config.md` |

---

## 🚀 التثبيت وحقن المهارة

لحقن مهارة `tidyfactor-doc` في أي مشروع برمجي:

```bash
npx @alwkala/tidyfactor-doc add-skill
```
